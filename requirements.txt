# Installs tinyagentos itself in editable mode, so core/, agents/,
# infrastructure/, storage/, api/ (see pyproject.toml's
# [tool.setuptools.packages.find]) are importable from anywhere --
# without this, `python scripts/run_benchmarks.py` fails with
# `ModuleNotFoundError: No module named 'core'` even though core/
# exists on disk, because nothing has told Python it's a package root.
# -e . resolves relative to wherever this file is installed FROM, so
# always run `pip install -r requirements.txt` from the repo root
# (D:\tinyagentos, alongside pyproject.toml) -- not from scripts/ or
# anywhere else.
-e .

# python-jose always installs these (even with the [cryptography] extra,
# which is what's actually used for signing/verification here) -- pin
# them explicitly so they don't silently resolve to the vulnerable
# floor versions python-jose's own setup.cfg allows.
# NOTE: python-jose 3.4.0 (the version bumped above from) hard-caps
# pyasn1<0.5.0, so it can't coexist with the pin below -- confirmed by
# the actual pip ResolutionImpossible error. 3.5.0 lifted that cap to
# pyasn1>=0.5.0 with no ceiling, which is why python-jose itself was
# bumped to 3.5.0 above.
# pyasn1: fixes recursion-based DoS, quadratic-time OID decode/encode,
#   and unbounded-tag-length integer growth in the BER/CER/DER decoders.
