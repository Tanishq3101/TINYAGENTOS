// ARCHITECTURE
Built for constrained hardware, not rented GPUs
01

Quantized runtime

Phi-3 Mini GGUF, CPU-only by default. Context window and thread count tune to what your device actually has.

02

Agent orchestration

Summarizer, extractor, and critic agents run as a supervised pipeline with retry and fallback built in.

03

Non-root by default

Containers run as an unprivileged user. Every input is validated before it reaches the model.

04

Structured everything

JSON logs, metrics, and health checks out of the box — no bolted-on observability later.
